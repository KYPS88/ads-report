เชื่อมต่อ Meta Marketing API

ดึงข้อมูลจริงจากบัญชีโฆษณาของคุณ
Token และ Account ID ถูกเก็บไว้ในเบราว์เซอร์เครื่องนี้เท่านั้น ไม่ถูกส่งไปที่อื่นนอกจาก graph.facebook.com — ดูวิธีสร้าง token ได้ใน README ของโปรเจกต์ หมายเหตุ: ถ้าเปิดหน้านี้ผ่าน claude.ai (artifact) การเรียก API จะถูกบล็อก ให้เปิดไฟล์ index.html จากเครื่องหรือโฮสต์เป็นเว็บก่อน หรือใช้สคริปต์ node scripts/fetch-data.mjs สร้าง data.json แทน
หรือ นำเข้าไฟล์ CSV จาก Ads Manager ไม่ต้องใช้ token
Export รายงานจาก Ads Manager เป็น .csv โดยแยกรายวัน (Breakdown → By time → Day) ที่ระดับโฆษณา และมีคอลัมน์: วัน, ชื่อโฆษณา, จำนวนเงินที่ใช้จ่ายไป, การแสดงผล, การเข้าถึง, การคลิกลิงก์, การเริ่มการสนทนาผ่านข้อความ, การซื้อ, มูลค่าคอนเวอร์ชั่นจากการซื้อ (หัวตารางภาษาอังกฤษก็ได้ ระบบตรวจจับให้อัตโนมัติ) — ข้อมูลอยู่ในเครื่องนี้เท่านั้น ไม่ถูกส่งไปไหน
หรือ ดึงจากลิงก์อัตโนมัติ (Google Sheet / CSV / JSON) สำหรับต่อกับ Make.com
วางลิงก์ CSV ที่เผยแพร่จาก Google Sheet (ไฟล์ → แชร์ → เผยแพร่ไปยังเว็บ → เลือก .csv) ระบบจะจำลิงก์ไว้และโหลดข้อมูลใหม่ทุกครั้งที่เปิดหน้านี้ — ให้ Make.com เป็นคนอัปเดตข้อมูลลง Sheet ตามรอบเวลา แดชบอร์ดก็สดเสมอโดยไม่ต้องทำอะไร แชร์ให้เพื่อนได้โดยเติม ?data=ลิงก์ ต่อท้าย URL ของแดชบอร์ด
